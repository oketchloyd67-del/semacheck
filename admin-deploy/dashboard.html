Kenya registry — CBK licensed digital lenders

A locally-cached copy of the Central Bank of Kenya's official directory of licensed digital credit providers. Search results check against this list to confirm whether a loan app/lender is genuinely CBK-licensed. CBK republishes this directory at a new URL each time they update it — there's no single "always current" link — so update CBK_DCP_DIRECTORY_URL in .env whenever a newer directory is published, then refresh here.
