Why teams pick our scam-checking API

SemaCheck provides a scam-checking API built for African and global fintechs, marketplaces, banks and job boards. Every call merges our community scam report database with the CBK licensed-lender registry, live web results, FTC and BBB scam trackers and Interpol fraud alerts, then returns a verdict, a confidence score and the evidence behind it — so your users can see the risk level of a phone number, M-Pesa paybill, business name, website or job offer before they send money or documents.

  • Scam verification API for phone numbers, paybills, websites, businesses and job offers.
  • Admin-approved reports only — every scam report is checked with supporting evidence before it reaches the API.
  • Webhooks that tell you when a watched subject changes verdict.
  • Free sandbox plan — unlimited test-mode checks with sk_test_ keys, no card required. Live checks start on a paid plan.
