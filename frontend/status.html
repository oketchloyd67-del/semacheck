How this works: the API, database and payments rows follow a live /api/ping probe against semacheck.onrender.com from your browser; the website row is confirmed by this page loading. If a component is down, the row turns red and the banner explains what is affected.

Uptime comes from an external probe every few minutes (a GitHub Actions job) plus the API's own self-check, which is reported separately because a process cannot report its own death. Probes that were not received are shown as no data, never as uptime, and a day with thin coverage is marked as partial. The external prober's schedule can be delayed by GitHub and pauses after prolonged repository inactivity — we would rather tell you that than promise a precision we do not have.
